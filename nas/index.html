Mediathek Plus aufs NAS

Trag ein, wo deine Filme, Serien und Dokus liegen – darunter steht die fertige docker-compose.yml für den Container Manager der Synology (oder docker compose auf jedem anderen NAS). Alles bleibt in deinem Browser, nichts wird gesendet. Schritt für Schritt: Anleitung.

Wohin soll was?

Die Freigabe genau so schreiben wie in der File Station (Video ≠ video). Unterordner dürfen leer bleiben; Serien landen darin in „Serie/Staffel 01“. Serien oder Dokus leer = zu den Filmen.

FreigabeUnterordner (optional)
Weitere Freigaben lassen sich später in der App unter Einstellungen → Download als Zielordner wählen, ohne die yml neu zu erzeugen.

Zugang und NAS

Synology: Freigaben liegen meist in /volume1, dein Benutzer ist meist 1026 / 100 (per SSH: id). Andere NAS: Pfad und Kennung entsprechend.

docker-compose.yml


    
      Den Ordner docker/mediathek-plus in der File Station anlegen. Dann Container Manager → Projekt → Erstellen → Pfad docker/mediathek-plus
      → Quelle „docker-compose.yml hochladen“ → die heruntergeladene Datei wählen. (Oder „docker-compose.yml erstellen“ und den kopierten Text einfügen.)
      Später eine Freigabe dazu? Hier neu erzeugen, im Projekt ersetzen, Projekt neu erstellen – Einstellungen und Merkliste bleiben.
    
  


  

    

      
Oder per SSH

      
    

    
SSH einschalten (Systemsteuerung → Terminal & SNMP), mit ssh benutzer@diskstation.local anmelden und alles auf einmal einfügen – die yml steckt schon drin.
